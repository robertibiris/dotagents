# Alternative C: Registered Hybrid

This fixture is the recommended production model: explicit scope maps and declaring-scope path provenance provide correctness, while native platform discovery and thin generated adapters improve ergonomics.

`northstar-holdings` is fictional. Its Aurora project must inherit Northstar and Aurora resources without loading the Solstice sibling. The fixture remains canonical without platform adapters; adapters are generated and tested in disposable copies.

Run `../validate.sh` from this directory's parent, or run the repository-level experiment validator from anywhere.
